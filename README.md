# Student Registration Form

Plain HTML, CSS and JavaScript. No build step.

## Run
Unzip and open `index.html` in any browser.

## Files
- index.html  – form markup
- style.css   – layout and theme (colours are CSS variables at the top)
- script.js   – validation, live student card, progress bar

## Connect to a backend
In script.js, find the `console.log('Student registered:', data)` line and replace it with a `fetch()` POST to your server.
